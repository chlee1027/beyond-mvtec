# Uninformed Students — Student–Teacher Anomaly Detection with Discriminative Latent Embeddings (요약)

> **한 줄.** ImageNet 조각으로 미리 배운 **교사 망**이 이미지의 모든 픽셀에 128 차원 서술자를 내고, 정상 이미지로만 학습한 **학생 망 3 개**가 그 서술자를 흉내 낸다. 학생들의 평균이 교사와 어긋난 정도(회귀 오차)와 학생끼리 어긋난 정도(분산)를 더한 것이 픽셀 이상 점수다. 이 레포에 중요한 것은 방법보다 **분할 지표 PRO 곡선 넓이의 정의**다 — 문턱을 바꿔 가며 결함 연결 성분마다 겹친 비율을 재고, 픽셀 거짓 양성률 30% 까지의 곡선 넓이를 최댓값 1 로 정규화한다(4.2절). MVTec AD 에서 이 값이 수용장 65 한 크기로 0.857, 세 크기를 묶으면 0.914 다. 연결성·문턱 개수·FPR 평균 방식·적분 방식은 원문에 적혀 있지 않다.

## 1. 용어

- **교사 (teacher)** $T$: 고정된 망. 이미지의 픽셀 $(r, c)$ 마다 그 픽셀을 가운데 둔 $p \times p$ 조각의 서술자 $y^T_{(r,c)} \in \mathbb{R}^d$ 를 낸다. 이 논문은 $d = 128$.
- **학생 (student)** $S_i$: 교사와 구조가 같고 무작위로 초기화해 정상 이미지에서 교사 출력을 회귀하도록 학습한 망. MVTec 에서 $M = 3$ 개.
- **수용장 크기 (receptive field)** $p$: 서술자 하나가 보는 조각의 한 변. $p \in \{17, 33, 65\}$. 작은 예시로, $p = 65$ 면 256x256 입력에서 서술자 하나가 한 변의 25% 를 본다(65/256, 내가 센 것).
- **연결 성분 (connected component)**: 정답 마스크에서 서로 이어진 결함 픽셀 묶음 하나. 작은 예시로, 한 이미지에 떨어진 긁힘 둘이 있으면 성분이 2 개다.
- **PRO (per-region overlap)**: 한 문턱에서 정답 연결 성분마다 「예측이 덮은 비율」을 재서 평균한 값. 표에 실리는 것은 이 값을 문턱을 바꿔 가며 그린 곡선의 넓이다(7절). 이 노트는 둘을 가르려고 곡선 넓이를 **PRO 넓이**라 부른다.
- **FPR (false positive rate)**: 정상 픽셀 중 이상으로 판정된 비율. 작은 예시로, 정상 9,000 픽셀 중 90 픽셀을 이상이라 하면 1%.
- **픽셀 AUROC**: 픽셀 하나하나를 표본으로 잰 ROC 곡선 넓이. FPR 0~1 전 구간을 적분한다. **이 논문은 MVTec 에서 이 값을 내지 않는다.**

## 2. 문제 / 동기

**사전학습 특징을 쓰는 이상 탐지가 얕은 모델(1-NN, K-Means, 가우시안) 때문에 학습 특징을 솎아 내고 차원을 줄여야 하던 제약을, 깊은 망으로 특징 분포를 암묵적으로 배우는 방식으로 없앤다.**

논문이 적은 앞선 연구의 막힌 곳(1 · 2절):
- 생성 모델(GAN, VAE, 오토인코더)은 픽셀 재구성 오차나 우도로 점수를 매기는데, 재구성이 부정확하거나 우도가 잘 보정되지 않는다고 적는다([8, 22] 인용).
- 사전학습 특징 + 얕은 모델([23, 24])은 조각을 잘라 하나씩 망에 넣어 느리고, 학습 조각을 표본 추출하고 PCA 로 차원을 줄여야 한다.
- 완전 합성곱으로 특징을 뽑는 [30] 은 풀링으로 해상도가 떨어지고 단봉 가우시안 하나로 분포를 맞춘다.

## 3. 핵심 기술 (짧게)

**① 교사 사전학습 (3.1절, 그림 3).** 조각 크기 입력을 받는 망 $\hat{T}$ 를 ImageNet 무작위 조각으로 학습한 뒤, [4] 의 변환으로 이미지 전체에 한 번에 조밀한 서술자를 내는 $T$ 로 바꾼다. 손실은 세 항의 가중합(식 (6)):
- 지식 증류 $L_k$ (식 (1)): $\hat{T}$ 의 출력을 완전연결 디코더로 늘려 ImageNet ResNet-18 의 512 차원 완전연결 층 출력과 맞춘다.
- 삼중항 거리 학습 $L_m$ (식 (2)~(4)): 사전학습 망이 없을 때를 위한 자기지도 대안.
- 상관 줄이기 $L_c$ (식 (5)): 미니배치 서술자의 상관 행렬 비대각 원소 합.
- MVTec 교사는 $\lambda_k = \lambda_c = 1$, $\lambda_m = 0$. 이유는 「MNIST · CIFAR-10 에서 가장 좋았다」(4.2절).
- 설정: Adam, 학습률 $2 \times 10^{-4}$, 가중치 감쇠 $10^{-5}$, 배치 64, $5 \times 10^4$ 반복, $d = 128$. 이미지를 한 변 $\{4p, \dots, 16p\}$ 로 키운 뒤 $p \times p$ 를 무작위로 자른다.

**② 학생 앙상블 (3.2절).** 교사 서술자의 성분별 평균 $\mu$ 와 표준편차 $\sigma$ 로 정규화한 목표를 학생이 회귀한다(식 (7), 픽셀 평균 제곱 $\ell_2$). MVTec: 256x256 으로 줄인 정상 이미지, 100 에폭, 배치 1, Adam 학습률 $10^{-4}$, 감쇠 $10^{-5}$, $M = 3$.

**③ 점수 (식 (8)~(11)).** 회귀 오차 $e_{(r,c)}$ = 학생 평균과 정규화된 교사 서술자의 제곱 거리. 예측 분산 $v_{(r,c)}$ = 학생 출력 제곱 노름의 평균 − 학생 평균의 제곱 노름. 둘을 **정상 검증 이미지**에서 잰 평균 · 표준편차로 각각 표준화해 더한다. 검증 이미지를 어디서 떼었는지는 적혀 있지 않다.

**④ 여러 크기 (3.3절, 식 (12)).** $p = 17, 33, 65$ 의 교사-학생 쌍 셋을 따로 학습하고, 표준화한 점수 지도를 평균한다. 결함이 수용장의 일부만 덮으면 서술자가 정상 쪽을 주로 담아 놓친다는 것이 동기다.

구조는 합성곱과 최대 풀링만 쓰고 활성 함수는 기울기 $5 \times 10^{-3}$ 의 leaky ReLU (표 4 · 5). 장비, 학습 시간, 추론 시간, 반복 실행 수는 적혀 있지 않다.

## 4. 평가 (읽은 범위)

- **데이터셋**: MNIST · CIFAR-10 (한 부류만 정상으로 둔 단일 부류 분류, 부류 10 개씩), MVTec AD (본문: 「5000 장 넘는 고해상도 이미지, 물체 10 · 질감 5 부류」).
- **지표**: MNIST · CIFAR-10 은 이미지 AUROC. **MVTec 은 PRO 넓이 하나뿐**이다 — 이미지 AUROC 도 픽셀 AUROC 도 없다.
- **비교 상대**: 교사 서술자 위에 맞춘 얕은 모델 셋(1-NN, OC-SVM, K-Means, PCA 로 분산 95% 남김)과 완전연결 오토인코더 둘(ℓ2-AE, VAE), MVTec AD 논문 [7] 의 방법 셋(SSIM-AE, AnoGAN, CNN-Feature Dictionary). 앞의 다섯은 같은 교사 특징을 쓰고, 뒤의 셋은 [7] 의 하이퍼파라미터로 저자들이 돌렸다(부록 C: 「same hyperparameters as ... [7]」, CNN-Feature Dictionary 만 조각 65 · 보폭 4 로 바꿈). MNIST · CIFAR 의 OCGAN 은 「report numbers」라고만 적어 다시 돌렸는지 옮겨 왔는지 알 수 없다.
- **장비**: 적혀 있지 않다.

## 6. 이 논문이 스스로 적은 한계

따로 한계 절은 없다. 본문에서 스스로 짚은 것:
1. 결함이 수용장의 일부만 덮으면 서술자가 정상 쪽을 주로 담아 성능이 떨어진다. 입력을 줄이면 해상도를 잃는다(3.3절). 여러 크기가 이 답이다.
2. 큰 수용장이 나은 부류(Bottle, Cable)와 작은 수용장이 나은 부류(Wood, Toothbrush)가 갈린다(표 3 본문).
3. **PRO 넓이를 높은 FPR 까지 적분하지 않는 이유**: 「FPR 이 높으면 입력의 넓은 부분이 잘못 이상으로 표시되어, 완벽한 PRO 값도 더는 의미가 없다」(4.2절).
4. MNIST · CIFAR 같은 작은 데이터에서는 학습 벡터를 전부 저장하는 1-NN 이 「예외적으로 잘 된다」(4.1절).

## 7. PRO 구현 명세

### 7.1 원문 문장 (4.2절, 7쪽) — 정의의 전부

> We compute a threshold-independent evaluation metric based on the per-region-overlap (PRO), which weights ground-truth regions of different size equally. ... For computing the PRO metric, anomaly scores are first thresholded to make a binary decision for each pixel whether an anomaly is present or not. For each connected component within the ground truth, the relative overlap with the thresholded anomaly region is computed. We evaluate the PRO value for a large number of increasing thresholds until an average per-pixel false-positive rate of 30% for the entire dataset is reached and use the area under the PRO curve as a measure of anomaly detection performance. ... We normalize the integrated area to a maximum achievable value of 1.

보태는 문장은 표 1 캡션 하나다: 「the normalized area under the PRO-curve up to an average false positive rate per-pixel of 30% ... It measures the average overlap of each ground-truth region with the predicted anomaly regions for multiple thresholds.」 식은 원문에 없다.

### 7.2 항목별로

| 항목 | 원문이 정한 것 | 적혀 있지 않은 것 |
|---|---|---|
| 이진화 | 점수를 문턱으로 잘라 픽셀마다 이상 / 정상 | 경계 포함 여부(`>` 인지 `>=` 인지) |
| 결함 영역 | **정답 마스크**의 연결 성분 하나하나 (예측 쪽이 아니다) | 4-연결인지 8-연결인지, 마스크를 256 으로 줄일 때의 보간 |
| 영역별 겹침 | 「relative overlap」 — 성분 중 이상으로 판정된 픽셀의 비율로 읽힌다 | 분모를 식으로 적지 않았다 |
| 한 문턱의 PRO | 성분별 겹침의 평균 (표 1 캡션 「average overlap of each ground-truth region」), 크기와 상관없이 같은 무게 | 평균을 부류 안 **모든 성분**에 대해 한 번 내는지, **이미지별로** 낸 뒤 평균하는지 |
| 문턱 훑기 | 「a large number of increasing thresholds」 | **문턱 개수, 간격(균등 · 점수 분위)**, 시작점 |
| FPR | 「average per-pixel false-positive rate ... for the entire dataset」 | 정상 픽셀을 모두 모아 한 번 나누는지, 이미지별 FPR 을 평균하는지. 결함 없는 시험 이미지를 넣는지(「entire dataset」은 넣는다고 읽히나 명시는 없다) |
| 적분 상한 | **FPR 0.3** (본문 「30%」, 표 1 · 3 캡션 「up to ... 30%」) | 문턱이 FPR 0.3 에 정확히 닿지 않을 때 보간하는지 |
| 적분 | 「area under the PRO curve」. 가로축은 FPR 로 읽힌다(상한이 FPR 로 주어지므로) | 사다리꼴인지 계단인지, FPR 0 쪽 끝을 어떻게 잇는지 |
| 정규화 | 「maximum achievable value of 1」 | 나누는 수를 숫자로 적지 않았다. PRO 최댓값 1 × 폭 0.3 이 넓이 최댓값이므로 **0.3 으로 나누는 것과 같다**(내 해석) |
| 평균 단위 | 표가 부류마다 값을 주고, Mean 행은 15 부류의 단순 평균과 맞는다(4절, 내가 센 것) | 「entire dataset」이 부류 하나를 뜻하는지는 문장으로 적혀 있지 않다 — 표가 부류별이므로 부류 단위로 읽는다 |
| 해상도 | 입력을 256x256 으로 줄이고, 점수 지도도 입력과 같은 크기다(3.3절) | 정답 마스크를 256 으로 줄여 쟀는지 원 해상도로 쟀는지 |

**방향 헷갈림.** 「increasing thresholds until ... 30% is reached」를 글자 그대로 읽으면 방향이 어긋난다 — 문턱을 올리면 FPR 은 내려간다. 적분 구간이 FPR 0~0.3 이라는 것은 캡션의 「up to ... 30%」로 정해진다.

### 7.3 식 (원문 문장을 식으로 옮긴 것, 원문에는 식이 없다)

부류 하나의 시험 이미지 전체에서 정답 연결 성분을 $C_1, \dots, C_K$, 정상 픽셀 집합을 $N$, 문턱 $t$ 에서 이상으로 판정된 픽셀 집합을 $P_t$ 라 하자.

$$\mathrm{PRO}(t) = \frac{1}{K} \sum_{k=1}^{K} \frac{\lvert C_k \cap P_t \rvert}{\lvert C_k \rvert} \qquad (1)$$

$$\mathrm{FPR}(t) = \frac{\lvert N \cap P_t \rvert}{\lvert N \rvert} \qquad (2)$$

$$\text{PRO 넓이} = \frac{1}{0.3} \int_{0}^{0.3} \mathrm{PRO} \; d\,\mathrm{FPR} \qquad (3)$$

식 (1) 은 「모든 성분에 같은 무게」 읽기, 식 (2) 는 「정상 픽셀을 모아 한 번 나누기」 읽기, 식 (3) 의 0.3 은 정규화 문장의 내 해석이다. 셋 다 원문이 고르지 않은 자리를 하나로 고른 것이다. 작은 예시로, PRO 가 FPR 0 에서 0, FPR 0.3 에서 0.9 까지 직선으로 오르면 넓이는 $0.5 \times 0.3 \times 0.9 = 0.135$, 정규화하면 0.45 다.

### 7.4 원문이 정하지 않은 자리에서 값이 갈리는 예 (내가 만든 숫자)

- **성분 평균 단위.** 이미지 A 에 성분 1 개(겹침 1.0), 이미지 B 에 성분 3 개(겹침 각 0.0). 모든 성분 평균 = 1/4 = 0.25, 이미지별 평균의 평균 = (1.0 + 0.0)/2 = 0.50.
- **FPR 평균 방식.** 이미지 1 은 정상 9,000 픽셀 중 900 이 거짓 양성(10%), 이미지 2 는 정상 1,000 중 500(50%). 모아 나누기 = 1,400/10,000 = 14%, 이미지별 평균 = 30%. 같은 문턱이 한 방식에서는 상한 안, 다른 방식에서는 상한에 닿는다.
- **연결성.** 대각선으로만 맞닿은 두 픽셀 덩어리는 8-연결이면 성분 1 개, 4-연결이면 2 개다.

### 7.5 픽셀 AUROC 와 PRO 가 다르게 재는 것 (내가 만든 숫자)

이미지 하나 100x100 = 10,000 픽셀. 정답에 큰 결함 1 개(30x30 = 900 픽셀)와 작은 결함 4 개(5x5 = 25 픽셀씩, 합 100)가 있다. 정상 픽셀 9,000. 두 점수 지도를 FPR 1% (정상 90 픽셀 오판)인 문턱에서 본다.

| 지도 | 잡은 것 | 픽셀 TPR (결함 픽셀 중 잡은 비율) | PRO (식 (1)) |
|---|---|---:|---:|
| A | 큰 결함 900 전부, 작은 결함 0 개 | 900/1,000 = **0.90** | (1 + 0 × 4)/5 = **0.20** |
| B | 작은 결함 4 개 전부, 큰 결함 300 픽셀 | 400/1,000 = **0.40** | (4 + 300/900)/5 = **0.87** |

픽셀 단위로는 A 가 낫고, 영역 단위로는 B 가 낫다. 논문 문장 「한 큰 영역을 맞게 분할하면 여러 작은 영역을 틀린 것을 메울 수 있다」가 지도 A 의 경우다.

**적분 구간도 다르다.** 픽셀 AUROC 는 FPR 0~1 전체를 적분하고 PRO 넓이는 0~0.3 만 본다. 결함 픽셀 점수가 정상 픽셀 상위 40% 보다는 낮고 나머지 60% 보다는 높은 지도는, FPR < 0.4 에서 결함을 하나도 못 잡고 FPR ≥ 0.4 에서 다 잡는다. 픽셀 AUROC 는 0.6, PRO 넓이는 0 이다.

### 7.6 PRO 의 출처

- **이 논문 본문**: 「It was also used by Bergmann et al. in [7]」. [7] 은 MVTec AD 논문(같은 저자 넷)이다.
- **[7] 쪽을 확인한 범위**: 이 레포의 MVTec AD PDF 4.3절에서 「overlap」이 나오는 문장만 찾아 읽었다. [7] 은 정상 검증 이미지로 **문턱 하나**를 정한 뒤 그 문턱에서 「relative per-region overlap」을 재고, 문턱과 무관한 값으로는 픽셀 ROC AUC 를 따로 낸다. 곡선 넓이나 30% 상한은 그 절에 없다.
- 그래서 **「영역별 겹침」은 [7] 에, 「문턱을 훑어 FPR 30% 까지 적분하고 정규화한 넓이」는 이 논문에 처음 적혀 있다.** PatchCore 와 PaDiM 이 쓰는 PRO 는 뒤의 것이다. 두 논문 사이의 다른 문헌은 이 노트의 범위에서 보지 않았다.

## 8. 이 레포 실험에 가져갈 것

**하나. 원문으로 정해진 PRO 세부는 셋뿐이다.** (가) 정답 마스크의 연결 성분마다 겹친 비율을 재서 크기와 상관없이 평균한다, (나) FPR 0.3 까지 적분한다, (다) 넓이를 최댓값 1 로 정규화한다. README 「지표」 절의 「거짓 양성률 0.3 까지 적분하고 0~1 로 정규화」는 원문과 같다. README 는 그 근거를 「MVTec AD 평가 관례」라 적었는데, 0.3 과 정규화가 적힌 원 출처는 이 논문 4.2절이다.

**둘. 나머지는 구현이 정해야 하고, 정한 값을 README 에 적어야 한다.** 7.2 표의 「적혀 있지 않은 것」 칸 — 연결성(4 / 8), 문턱 개수와 간격, FPR 을 모아 나누는지 이미지별 평균인지, 결함 없는 시험 이미지 포함 여부, 성분 평균 단위, FPR 0.3 에서의 보간, 적분 방식, 마스크 축소 보간. 7.4 의 예처럼 이 선택들은 값을 바꿀 수 있다. **이 논문만으로는 PatchCore 의 PRO 93.5 · PaDiM 92.1 이 어떤 선택으로 나온 값인지 알 수 없다** — PatchCore 논문도 「[6] 을 따른다」고만 적는다. 그래서 README 의 PRO 재현 판정 폭 ±1.0 이 구현 선택 차이까지 덮는지는 이 노트로 정해지지 않는다.

**셋. 평균 단위.** 이 논문의 Mean 행은 부류 15 개 PRO 넓이의 단순 평균이다(13 열 중 11 열이 ±0.001 안, 내가 센 것). 데이터셋 값을 낼 때 부류 값을 먼저 내고 평균하는 것이 원문 표와 같은 방식이다.

**넷. 해상도.** 이 논문은 MVTec 을 256x256 으로 줄여(자르지 않음) 쟀다. 정답 마스크를 몇 해상도에서 연결 성분으로 나눴는지는 적혀 있지 않다. 이 레포의 재현 단계(256 → 가운데 224)와 비교 단계(256, 자르지 않음)는 마스크도 같은 변환을 거쳐야 하고, 줄이면 작은 성분이 사라지거나 붙을 수 있다 — 어느 해상도에서 쟀는지 결과와 함께 적는다.

**다섯. 이 논문에서 가져올 재현 목표는 없다.** 이 레포는 학생-교사 방법을 돌리지 않는다. 이 논문의 MVTec 값(0.857 · 0.914)은 다른 방법의 참고값일 뿐이고, 이미지 AUROC · 픽셀 AUROC 는 이 논문에 없다. 다른 논문의 표에서 「Student」를 인용할 때 85.7 은 $p = 65$ 한 크기 값, 91.4 는 여러 크기 값이라는 것을 가른다.

**여섯. 지금 확인된 것은 여기까지다.** 논문이 잰 것: 표 1 · 2 · 3 · 6 · 7 의 한 번 돌린 값. 논문이 말만 한 것: 「얕은 모델은 용량이 모자라다」, 「생성 방법과 판별 임베딩 방법 사이에 간격이 있다」(5절에서 짚음). 내가 센 것: 평균 다시 계산(두 열 어긋남), 굵은 글씨 대조(세 칸 어긋남), 표 4 · 5 의 층 크기 계산, 7.4 · 7.5 의 예시 숫자.
